The agent team

Each role sees only the tools it needs.

  • Orchestrator

    Plans the task and hands the coding to the coder. Never runs code itself.

  • Coder

    Writes Rust, runs it in the sandbox, reads the result and fixes what failed.

  • Worker

    Takes small, well-defined side tasks. Cannot run code.

  • Reviewer

    Checks the answer against the sandbox evidence before you see it.

    Safety and limits
    
    
  
    
  
    Authority stays outside the agent. Only the trusted worker creates and destroys sandboxes, and the agent can only ask.
    
  
    
    
    Isolation
    gVisor, a non-root user and a read-only root filesystem. No host folders and no Docker socket inside.
    
    
    Network
    Off. Cloud and inference keys never enter a sandbox.
    
    
    Resources
    1 vCPU, up to 1 GiB of memory, 64 processes, 64 MiB of scratch space, 64 KiB of output and 2 minutes per run.
    
    
    Files out
    Regular files only: 1 MiB each, 4 MiB in total, eight at most.
    
    
    Cleanup
    Every sandbox is destroyed. Its memory stays reserved until the cleanup is confirmed.
    
    
    Not offered
    Nested Docker, browser and desktop sandboxes stay off until they pass their own qualification.
    
    
    Evidence
    Records collected by the worker. They are not an independent attestation or a security audit.
