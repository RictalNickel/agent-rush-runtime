        Safety and limits

        Authority stays outside the agent. The control plane holds every key, and the model's tools run only inside the session's box on the worker.

        Isolation
        Each session gets its own gVisor box: a non-root user, a read-only system, no host folders and no Docker socket.
        Network
        Public internet only. The box cannot reach cloud metadata, private networks, the worker itself or mail ports. No keys enter a box.
        Workspace
        Files in /workspace stay between messages. An idle box is removed after 30 minutes by default, and closing a session deletes its workspace.
        Steering
        A message sent while the agent works reaches it before its next step. Stop ends the turn after the current step.
        Turn limits
        By default 60 model steps and 30 minutes per turn.
        Record
        Every step is stored as an event, so the whole session can be replayed through the API.
