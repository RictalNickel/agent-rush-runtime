Architecture

Two VMs, one private link, no shortcuts

User

Browser over HTTPS (Let’s Encrypt, HSTS)

Control VM

Caddy gateway → Rust API on loopback

Agent engine, role allowlists, spend ledger

Login, CSRF, owner-scoped jobs (SQLite)

Calls the inference API; never runs code

Worker VM

nginx mTLS ingress on the VPC address only

Node manager owns Docker; no public ports

One gVisor sandbox per run, then destroyed

Requalifies itself every 90 minutes

Control ↔ worker: private Vultr VPC, client certificate and bearer token required. Worker reachable from the internet on SSH only.

The control VM is the only thing the public can reach. It holds the web app, the agent engine and the inference key, but it never executes generated code. The worker VM has the Docker authority and runs every sandbox. The two talk over a private Vultr VPC through an nginx proxy that requires a client certificate and a token. We tested the rejection paths: no certificate returns 400, a wrong token returns 401.
