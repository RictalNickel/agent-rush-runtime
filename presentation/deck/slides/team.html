The agent team

Four roles, each with only the tools it needs

RoleGLM 5.3 Flash effortMay do
OrchestratormediumPlan, delegate, supervise the coder, answer — never runs code
CoderxhighWrite Rust, run it in the sandbox, fix and rerun
WorkerhighSmall defined tasks, memory lookups — no code execution
ReviewerhighAudit the answer against the worker’s evidence — approve or send back

Every call goes to Vultr Serverless Inference. Role prompts are stripped to their own tools, and trusted code enforces each allowlist. Reasoning is capped so every role keeps room to answer, and every call reserves its worst-case cost before it is sent.

Each role sees a short system prompt listing only its own tools, and the engine rejects any tool outside the role’s allowlist even if a model asks for it — in testing, an orchestrator that tried to run code itself was refused and logged. The live demo runs every role on Vultr Serverless Inference with GLM 5.3 Flash; the roles differ in reasoning effort, and each call’s reasoning is capped at half its output budget so the model always has room to answer. Inference is pluggable: the same engine also runs on Anthropic Claude, with Opus for the orchestrator and reviewer and Haiku for the coder and worker.
