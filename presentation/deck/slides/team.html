The agent team

Four roles, each with only the tools it needs

RoleModel · effortMay do
OrchestratorOpus 5.5 · mediumPlan, delegate, supervise the coder, answer — never runs code
CoderHaiku 5.5 · xhighWrite Rust, run it in the sandbox, fix and rerun
WorkerHaiku 5.5 · highSmall defined tasks, memory lookups — no code execution
ReviewerOpus 5.5 · highAudit the answer against the worker’s evidence — approve or send back

Role prompts are stripped to their own tools, and trusted code enforces each allowlist. Haiku roles compact their context server-side at 100k tokens. Every call reserves its worst-case cost before it is sent.

Each role sees a short system prompt listing only its own tools, and the engine rejects any tool outside the role’s allowlist even if a model asks for it — in testing, an orchestrator that tried to run code itself was refused and logged. Inference is pluggable: the same engine runs on Vultr Serverless Inference, where every role uses GLM 5.3 Flash, or on Anthropic Claude with the per-role models shown here. Today’s live demo runs the Claude team.
