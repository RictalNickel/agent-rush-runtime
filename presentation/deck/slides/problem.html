The problem

An agent that can run code can also read your keys, call the internet and take down the server it lives on.

Most agent tools run generated commands next to the app, its credentials and its network. One bad step — a hallucinated command or an injected instruction — has the whole machine as its blast radius.

This is the core risk the Blast Radius Zero track is about. Generated code is untrusted code. If it runs in the same process or on the same host as your application, a single mistake or prompt injection can leak credentials, exfiltrate data or exhaust the machine.
