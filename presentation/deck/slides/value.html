Business value

Let agents do real work where mistakes are expensive

Who: teams that want AI agents to analyse data, test code or automate tasks on infrastructure that also holds customer data and credentials.

Why they buy: every run is isolated, capped and destroyed, and leaves a receipt an auditor can check — not a chat transcript.

How it grows: the worker advertises its capacity and admission follows it. Today one worker runs two jobs at a time; more worker VMs is the next step.

The value is trust. Companies want agents that act, but they cannot let model-generated code run next to production secrets. Agent Rush gives each action its own disposable box and a machine-checked receipt. Infrastructure is two small Vultr VMs at about eight cents an hour; in our runs a verified job cost between six and twenty cents in model usage. Today a single worker admits two jobs at a time; supporting several worker VMs is the next step, and automatic scale-out is not built.
