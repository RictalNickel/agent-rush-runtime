Honest limits

What we found, and what is not built yet

Threads are not PID-capped

gVisor counts processes, not threads, against the 64-PID cap. Thread growth is bounded by memory and CPU instead.

Safety filters can decline

Prompts that ask agents to probe the sandbox were refused by the model’s cyber classifier; we ran our probe directly instead.

CLI sandboxes only

Browser, nested-Docker and desktop profiles are designed but disabled until they pass the same qualification.

No automatic scale-out

One worker today. Memory grows between attempts, never inside a running sandbox.

We would rather show the edges than hide them. Each of these came from testing the live system. The thread finding and the safety-filter refusals are in the evidence files; the disabled profiles are refused by the product rather than run without qualification.
