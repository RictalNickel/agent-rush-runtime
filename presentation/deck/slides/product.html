What it does

Plan, execute, verify — every step contained

01

Plan

An orchestrator agent breaks the task down and delegates the code to a coder agent.

02

Execute

The code runs in a fresh gVisor sandbox on a separate worker VM, then the sandbox is destroyed.

03

Verify

The worker issues a receipt — exit code, checks, artifact hashes, cleanup — and a reviewer agent audits the answer.

The user types a task in the web app. Three things happen. The orchestrator plans. The coder's program runs only on the private worker, in a sandbox created for that run. The worker — not the model — decides whether the run succeeded, and an independent reviewer checks that the final answer matches the evidence. A model cannot mark unexecuted work as verified.
