Boxoro gives the app or agent you already have a contained subagent. It does real work offsite, and anything that goes wrong stays in one box.
Useful agents run code and drive a browser. Run that on your own servers and one prompt injection can reach your keys, your network and your host.
Plug it into the app or agent you already have, over MCP or one REST call. The subagent does the work in its own box on Vultr and hands back the result.
Each session gets its own gVisor box with a shell, a browser and files. Nothing secret is inside, it cannot reach your network, and every resource is capped.
On the public instance the agent built a kanban board, ran it, and tested it in its own browser over three turns. 92 tool calls for $0.0244 of model time.
From inside a live box we tried eight escapes: stealing cloud credentials, finding keys, reaching the private network and the host, spam, system files, a fork bomb and an 8 GiB memory grab. 8 of 8 were blocked. The fork bomb and the memory grab only killed that box, which restarted on the next call with its files kept.
Every agent model call goes to Vultr Serverless Inference, GLM 5.3 Flash. Both VMs run on Vultr in Chicago: a public control VM and a private 16 vCPU worker, which has run 72 agent sessions at once.
It is live now. Plug it into your app, or open the URL and give it a task.
