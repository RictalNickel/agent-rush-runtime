Vultr-Placeholder-Test123: plug a contained subagent into the app or agent you already have. It does real work offsite, and the damage stays in one box.
Agents that do real work need to run code and browse. On your own servers that is a huge blast radius: one prompt injection away from all of it.
Each session gets one gVisor container on a private worker VM. No credentials ever enter it, and an egress filter keeps it on the public internet.
This is the point of it: plug it into the app or agent you already have. Add it to Claude Code, Cursor or any MCP client as one remote server, or start a session with one POST. Your app hands off the task; the subagent runs code and a browser offsite, in its own box on Vultr, and hands back the result. Turn ends are POSTed to your webhooks, signed.
Your app talks to the control VM, which runs the sessions and calls Vultr inference. It never runs a command the model chose. The worker VM is private, reached over mTLS, and runs the boxes behind the egress filter.
These are the agent's built-in tools. Shell, browser, files, research and conversion run in the box. Skills, its own config and MCP run in trusted code on the control VM.
On the public instance the agent built a kanban board with a Python backend, ran it, and used it in its own browser: add three cards, move one to Done, reload. Then dark mode in turn two, and deleting a card in turn three. 92 tool calls, $0.0244.
Five ordinary office requests, one turn each: totals from a CSV, a bar chart, a memo as Word and PDF, renaming messy files, and shrinking the chart to a JPG. Every turn took under ten seconds. 7 tool calls, $0.0034. The memo's revenue figures are right, but the model invented the units and the softest month: it wrote them without computing.
One request: research HTTP 418, build a lookup app, test it in the browser, write a PDF report. Mid-turn I sent an interjection asking for a footer. First turn 35 seconds, 17 tool calls over two turns, model cost $0.0054.
A probe session asked the agent to reach metadata, the worker, the host's SSH and mail ports. Every attempt failed at the network. A 4300 MiB write stopped at the workspace quota. On the deployed binary, 9 of 9 box checks and 10 of 10 job checks pass.
Every agent model call goes to Vultr Serverless Inference, GLM 5.3 Flash. Both VMs are Vultr instances in Chicago. The 16 vCPU worker has run 72 agent sessions at once through the public URL. These are the real model costs of the demos.
