# Demonstration plan

## One-sentence pitch

Agent Rush gives an AI agent a disposable Rust development environment and gives its operator execution evidence whose authority stays outside the model.

## Three-minute demonstration after cloud acceptance

1. Show the real Vultr-hosted HTTPS workspace and the current private repository. Explain that contest publication awaits the user's authorization, since the provided checklist calls for public source.
2. Submit a concrete revenue-analysis task. Show a real Vultr inference request receipt and the native Rust controller's validated sandbox request. No local shell runs in the controller.
3. Open the actual execution record: output, result.json, artifact hash, independently collected exit status and cleanup. Download the evidence JSON and artifact.
4. Run an approved synthetic containment task against a canary. Show denied host/socket/secret/network access and a bounded timeout. Show the empty task inventory after destruction. Do not use real credentials as the canary.
5. Show admitted resource caps, genuine host measurements and the current spending/resource ledger. Distinguish a ceiling from dedicated cores. Show temporary machines deleted after the active demonstration window.

## Current build honesty

Do not record the local queue and describe it as a live model run. Do not present the earlier containment probe as a fully qualified worker: memory enforcement failed, and the current worker refuses this managed host. Do not animate invented metrics or replace absent provider receipts with fixtures. No end-to-end live demonstration video has been recorded yet.

The sample examples/revenue.rs fixture is a reproducible offline workload, not proof that an LLM generated it. It asserts North=1600 and total=3400, writes result.json and must be executed through a qualified sandbox, never treated as a substitute for the real provider/controller flow.

The presentation is a progress deck grounded in recorded local evidence. Update the deployment, price, benchmark and verification slides only after those checks actually pass.
