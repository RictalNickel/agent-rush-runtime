# OCI images and native worker deployment

`deploy/images.lock.json` records immutable linux/amd64 inputs. The official Rust 1.90.0 Bookworm image is the offline CLI compiler/execution profile; the Ubuntu 24.04 image is the native control application's minimal runtime. Both have been downloaded locally. No Python image is used. See THIRD_PARTY_NOTICES.md.

Build with `bash scripts/build-images.sh` from a trusted shell that can use local Docker. The script builds locked Rust release code, verifies the reviewed public CA bundle, creates a temporary build context from exactly the executable/public certificates/license/state directory, builds without network RUN steps and exports `/workspace/artifacts/agent-rush-control-image.tar.gz`. It never copies the checkout, credential directory, environment files, SSH keys, inference key or infrastructure key. Session proxy root certificates are excluded from the production trust bundle. Existing official image inputs are reused or pulled by digest.

The control image runs as UID/GID 65532. Start it with a read-only root, dropped capabilities, no-new-privileges, bounded writable `/data`, and loopback-published HTTP behind HTTPS ingress. Inject the private control configuration at runtime using an owner-only environment file; keep it outside images and Git. Production secure cookies stay enabled. Mount only its database and explicitly required private worker TLS identities. A control container receives no host Docker socket. Synthetic smoke-test passwords must never be reused for production.

The worker is a native Rust host service (`deploy/worker.service`), separate from the control container. It alone has Docker management authority and receives no inference/infrastructure key. Install Docker with functioning host cgroups and runsc without `--ignore-cgroups`, pull the locked sandbox image, then run `agent-rush qualify --output /var/lib/agent-rush/qualification.json` as the service identity. Set AR_QUALIFICATION_REPORT and only start the worker if qualification passes. Reports expire after two hours and must match the current host fingerprint/image; expiry refuses new tasks while existing cleanup/evidence remains accessible.

The current managed host lacks memory/CPU/PID enforcement. It is refused before any task probes and must not be used as the execution worker. The public CA bundle is pinned to the current builder's Debian ca-certificates 20250419 public Mozilla roots; a builder with different roots must deliberately review/update the bundle hash rather than silently changing image trust.

Session boxes use a separate workspace image, `deploy/workspace.Dockerfile`: the pinned Playwright Ubuntu 24.04 image plus shell tools, Python, Node, a minimal Rust toolchain, pandoc, LibreOffice, ImageMagick, ffmpeg and the helpers in `deploy/box-tools`. It is built on the worker (`bash scripts/build-images.sh --workspace`), and the worker runs the exact digest it built (`AR_BOX_IMAGE`). `agent-rush qualify-box` must pass for that digest before any box starts; the qualified digest is in `deploy/images.lock.json` as `workspace`.

Optional browser, nested Docker and desktop profiles for one-shot jobs have no qualified implementation and remain disabled. Large optional images are not downloaded merely for an unavailable feature. Downloading an OCI image does not prove isolation, nesting, successful execution or resource enforcement.
